### Added
- Blank application window launches via `python -m lector` (Milestone 1 skeleton).
- Home screen with sidebar navigation and "Open PDF" button (native file dialog).
- PDF rendering in book layout via PyMuPDF — opens and displays any PDF file.
- Page navigation: Previous/Next buttons and arrow keys / Page Up / Page Down.
- Jump-to-page spinbox control.
- Zoom in/out via toolbar buttons or `=` / `-` keys.
- Light theme applied throughout: all color tokens from the design system are wired up.
